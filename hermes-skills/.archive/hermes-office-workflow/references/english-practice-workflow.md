# 英语练习工作流（参考案例）

此文件记录了为中文用户（初级水平）搭建 Hermes 英语练习系统的一次完整实践。

## 用户画像

- **职位**：企业二级部门主管（客户成功部）
- **英语水平**：初级（Elementary）
- **目标**：职场英语 + 口语对话
- **每天可投入**：45分钟以上（认真投入型）
- **练习时间**：晚上下班后（8点开始）
- **练习频率**：每天（含周末）
- **交流方式**：日常中文，英语练习时切换英文

## 完整搭建步骤

### 1. 编写 Persona 文件（~/.hermes/SOUL.md）

这是最重要的第一步。Persona 文件定义 Agent 的身份和交互规则，每次对话自动生效。

核心配置要点：
- 日常交流使用中文
- 英语练习模式通过关键词触发（如 "English time:"）
- 练习结束后自动切回中文
- Agent 需要以鼓励、耐心的英语教练风格出现
- 轻微纠正用户错误（重复正确说法 + 简单解释规则）
- 每轮练习引入 1-2 个职场英语短语（含中文翻译 + 例句）

### 2. 制定学习计划（~/.hermes/english-plan.md）

按阶段组织，每阶段4周：

| 阶段 | 周期 | 主题 | 语法重点 |
|------|------|------|----------|
| 第一阶段：打基础 | 第1-4周 | 自我介绍→日常工作→客户沟通→汇报工作 | be动词、一般现在时、简单疑问句 |
| 第二阶段：场景应用 | 第5-8周 | 电话沟通→会议英语→邮件写作→问题处理 | 过去时、将来时、情态动词 |
| 第三阶段：提升流利度 | 第9-12周 | 演示介绍→谈判说服→跨文化沟通→综合实战 | 完成时、条件句、被动语态 |

每日45分钟结构（文字模式）：
1. **Warm-up (5min)** — 复习前一天内容
2. **New Input (15min)** — 学习新词汇/句型，用表格展示（英文+中文+备注）
3. **Practice (15min)** — Agent 扮演角色（客户/同事/老板），用户打字回复，Agent 纠错
4. **Review (10min)** — 总结新单词，列出错误点

### 3. 设置定时提醒（Cronjob）

```python
cronjob(
    action='create',
    schedule='0 20 * * *',     # 每晚8点
    name='英语练习日常提醒',
    prompt='提醒用户开始45分钟英语练习，询问今天想练什么主题',
    skills=['hermes-agent'],
    deliver='origin'
)
```

### 4. 用 TTS 弥补听力练习

文字会话无法练听力，使用 text_to_speech 将当天学习内容转为语音：

```python
text_to_speech(
    text="Hello, my name is Yang Jiayang. I work at SmarDaten...",
    output_path='/path/to/output.mp3'
)
```

用户可离线反复听。听完后删除。

## 常见陷阱

1. **不要默认用英文交流** — 如果用户未指明，先用中文。用户说 "English time" 才切英文。
2. **不要替用户决定练习进度** — 用户是否开始练习由ta自己决定，cron 只是提醒。
3. **纯文字练习的局限** — 用户注意到不能发语音，不要强行要求口语输出。让用户在打字时心里默读。
4. **Persona 文件位置** — `~/.hermes/SOUL.md`，不是 skills 目录下，也不是 config.yaml。
