# 企业微信（WeCom）消息历史获取

## 核心限制

**Hermes 无法事后拉取企业微信的聊天记录。** 这不是配置问题，是平台架构决定的。

### 原因

1. **Gateway 是实时转发，不持久化** — 企业微信的消息通过 WebSocket 实时流到达 Hermes，Hermes 处理后即丢弃，不会保存到数据库
2. **企业微信 API 不开放历史消息拉取** — 企业微信的服务商 API 只能获取应用主动发送的消息状态，不能拉取用户之间的聊天内容（隐私保护限制）
3. **Gateway 日志只有连接状态** — `gateway.log` 记录的是连接/断开/重连事件，不记录消息正文

### 能获取到什么

| 数据来源 | 可获取内容 |
|---------|-----------|
| gateway.log | 连接状态、断开时间 |
| request_dump | 仅当 API 调用失败时记录的请求/响应 |
| state.db | 当前 CLI 会话的消息，不含 gateway 会话 |

### 正确做法

如果用户问"帮我整理企业微信今天的聊天内容"：

1. 解释 Hermes 无法事后拉取企业微信聊天记录
2. 建议用户在企业微信中手动将需要整理的内容转发给 Hermes 机器人
3. 或者用户截图/复制粘贴内容，Hermes 帮助分析和整理

### 与微信（Weixin）的区别

微信 iLink Bot 同样不能拉取历史消息，但微信有「聊天记录迁移」功能可以在手机端操作。企业微信因为是企业级 IM，隐私保护更严格。
