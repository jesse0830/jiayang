## React Rendering Quirk

- 登录进入首页后，`browser_snapshot(full=true)` 有时显示为空白页（仅main→main→main深度嵌套），但 `document.body.innerText` 实际已有完整文本内容。
- 解决方案：优先使用 `browser_console(expression='document.querySelector(...).innerText')` 读取内容，而不是依赖 `browser_snapshot`。
- 点击"要我办"后需要等待 2-3 秒让 React 渲染完成，否则 snapshot 显示空白。
- `browser_console(expression='document.body.innerText')` 是最可靠的内容提取方式，即使 snapshot 为空也能获取到渲染后的文本。

## Pitfalls

1. **Session 不持久** — `browser_navigate` 到 OA 首页后可能被重定向回登录页，需要重新输入凭据。第一次登录成功后尽量使用 SPA 内部导航（点击按钮），不要用 `browser_navigate` 跳转。
2. **"更多>"按钮行为** — 点击"流程"区域的"更多>"会跳转到"事件流工作台"页面，URL 中的 appid 会变化（从 1640627701456342 → 8864182915840980），但页面不会自动选中任何子标签。需要手动点击"待我处理"标签才能看到内容。
3. **事件流工作台的默认显示** — "事件列表"标签下默认显示"暂无数据"（0条），这不代表没有待审批。必须切换到"待我处理"标签。
4. **分页限制** — 列表支持 10条/页 的分页显示，目前仅1条。如果后续数据量增加，需处理分页。
5. **"待我处理"≠"待我审批"** — 首页统计数据中的"待我审批: 6"可能比"待我处理"标签下的实际记录多，差异原因不明（可能是其他状态/模块的待办）。
