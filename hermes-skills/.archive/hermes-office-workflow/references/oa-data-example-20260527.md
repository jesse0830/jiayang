## 完整数据抓取流程

1. 登录 OA (https://oa.smardaten.com)
2. 首页 → 点"要我办" → 在"我要办"区找"费用报销"图标
3. 员工报销 → 出差报销 tab → 抓取全部7页
4. 员工报销 → 个人报销 tab → 抓取全部1页
5. 侧边菜单 → 招待报销 → 招待报销申请 → 抓取全部3页
6. 筛选非结束状态记录，按模块汇总金额

## 已知坑点

- **React DOM 残留**：切换 tab 后旧 tab 的 DOM 节点可能残留。始终按 type 列或 code 列筛选有效行
- **空头行**：Ant Design 的 `ant-table-tbody` 包含表头行，用 `cells.length > 4` 过滤
- **Ref ID 变化**：每次导航后所有元素的 ref ID 都会变，不能依赖缓存
- **列索引因模块而异**：金额列在出差报销是 c[12]，在个人报销是 c[11]
- **分页后有延迟**：翻页后要 sleep 2-3 秒等 React 渲染完成再提取
