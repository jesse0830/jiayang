## 技术要点

1. **招待报销(旧)标签页**：进入后显示提示"招待报销，请从招待报销申请发起！"，此页面为查询入口，无独立数据表格，不需要提取
2. **翻页时确认实际页数**：虽然 `.ant-pagination-item` 显示7页（出差报销），但第7页内容与第6页相同，实际数据只到第6页
3. **browser_console 变量声明**：用 `var` 或 IIFE 避免 `let/const` 重复声明错误。最佳实践：`(function(){ var data = []; ... return JSON.stringify(data); })()`
4. **金额列差异**：招待报销申请和出差报销是 c[12]，个人报销是 c[11]
