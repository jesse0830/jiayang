# 面试备考

流程：问清公司/岗位/轮次/考点 → 调研官网+JD → 按岗位视角出题（概念+落地+场景，每题给答法）→ 结合数睿背景做优势 → 交付 md 到 98 hermes。

陷阱：长 md 静默截断（write_file 超 ~7500 字符）。解法：write_file 第一部分 + terminal cat >> heredoc 追加 + read_file 验证。
