# 双表逐人匹配算法（姓名重名消歧，2026-08-24 验证跑通）

适用：两个学期/版本费用表逐人对比，姓名列存在重名（同名校不同人，如
陈霞=四年级/综合两个岗位）。核心原则：**按行累加，绝不按姓名 dict 覆盖**。

## 匹配算法（26春 为主体）

```python
for p in spring:  # 无重名的一方为主体
    ms = [f for f in fall if f['name'] == p['name']]
    if len(ms) == 1:
        p['fall'], p['status'] = ms[0], 'ok'
    elif len(ms) > 1:                      # 重名：按年级列消歧
        gm = [f for f in ms if f['grade'] and f['grade'] == p['grade']]
        if len(gm) == 1:
            p['fall'], p['status'] = gm[0], 'ok_grade'
        else:
            p['status'] = '重名待确认'     # 年级也对不上 → 挂起问用户，不猜
    else:
        p['status'] = '仅26春'             # 另一表无此人
# 25秋 中未被匹配的行 → status='仅25秋'（金额保留，26春 侧记 0）
```

实测结果：ok=179 + ok_grade=2（陈霞-四、邱建花-三）+ 仅26春=20 + 仅25秋=12。
重名两行**不合并、不覆盖**，各自保留金额（陈霞-综合 780 与 陈霞-四 9570 分列展示）。

## 关键坑

1. **dict 按姓名聚合会覆盖重名**：25秋555 陈霞×2、邱建花×2 → dict 覆盖后总额 1272990，
   逐行累加 = 1289380，差 16390。**先 Counter 查重，再决定匹配策略**。
2. **列字母转数字**：公式解析用 `re.findall(r'([A-Z]+)', s)` 提取列字母后，递归取值前
   必须 `col_num()` 转数字（`n = n*26 + (ord(ch)-64)`），否则 openpyxl 传字母列取值返回 0。
3. **同名不同写法不自动合并**：徐慧婷↔徐惠婷、李嘉慧↔李佳慧、陈芳（音乐）↔陈芳（音）——
   标注让用户确认，不猜。
4. **带括号标注不算重名**：26春333 的「陈霞（美术）」「陈芳（音）」名字串含括号，
   Counter 不判重，是表内自带的区分手段。
5. **总额一致 ≠ 口径一致**：两版总额相同但分项构成不同（弹性-8857/优学+6540/普调+2317
   恰好抵消）——核对必须逐项对比分项构成，不能只看总额。
