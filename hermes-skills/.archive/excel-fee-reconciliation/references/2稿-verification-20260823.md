## 模拟公式核算（openpyxl 核心方法）
```python
import openpyxl, re
from openpyxl.utils import column_index_from_string
wb = openpyxl.load_workbook(path, data_only=False)  # 公式模式
ws = wb['2稿']

def calc_formula(s):
    if s is None: return 0
    if isinstance(s, (int, float)): return s
    m = re.fullmatch(r'=([A-Z]+)(\d+)\*(\d+)', str(s).strip())
    if m:
        col, row, price = m.group(1), int(m.group(2)), int(m.group(3))
        base = ws.cell(row=row, column=column_index_from_string(col)).value
        return 0 if base is None else base * price
    return None  # 其他公式（SUM 等）另行处理

# 每行 S 合计 = E+G+I+K+M+O+Q+R 逐成员取值；R201/R202 是数字直接加
```

**坑1 — 正则贪婪**：`=(\w+)(\d+)\*(\d+)` 会把 `D2*20` 的 `D2` 吞进 `\w+`（列名错）→ 必须 `=([A-Z]+)(\d+)\*(\d+)` 只匹配字母列名。
**坑2 — 缓存值不可信**：data_only=True 读缓存 S 列合计 = 2,241,666（WPS 保存的旧值），而模拟公式 = 1,109,833。**以模拟公式为准**，缓存只做交叉参考。
**坑3 — 底部分项加总验证**：先按列（早读/午值/晚辅/过关/弹性/社团/优学/普调）加总，再逐行验证，两边一致才算对。
