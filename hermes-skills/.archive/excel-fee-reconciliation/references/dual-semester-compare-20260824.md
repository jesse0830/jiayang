# 双表逐人对比案例：25秋555 vs 26春333（2026-08-24）

用户给两个学期表，要求：①统计每人 25秋/26春 各拿多少钱 ②26春比25秋少拿多少
③26春每人日均 ④核对 26春333 金额是否正确。

## 文件结构

**25秋555.xlsx（Sheet1，24 列 A-X，97 天）**
- 表头 R2：A=序号 B=年级 C=姓名 D=早读 E=金额 F=午值 G=金额 H=晚1 I=金额
  J=过关 K=金额 L=弹性 M=金额 N=校级社团 O=金额 P=优学 Q=金额 R=普调 S=金额
- 数据行 R3-R195（序号 1-193），S 列 = `=E+G+I+K+M+O+Q+R`
- 底部草稿区：C199=1205020、C200=37200、C201=`=SUM(C199:C200)`（另一口径，非主总额）

**26春333.xlsx（「3稿」sheet，20 列 A-T，84 天）**

  I=晚辅费用 J=过关 K=过关费用 L=弹性打卡 M=弹性费用 N=校级社团 O=社团费用
  P=优学社团 Q=优社费用 R=普调 S=合计
- 数据行 R2-R202（201 人：序号 1-200 + 陆校），S 列公式同上
- R203 = SUM(S2:S202)；底部草稿区 D207=收取费用 965252.5、D208=资金缺口 180580.5、
  D209=卞一凡 5000、D210=`=SUM(D207:D209)`=1150833、H210=行政 30000、J210=目前 1120833、
  L210=`=D210-H210-J210`（=0 正好平）
- C212 手写「上学期 1289380 97天」= 25秋555 模拟总额的交叉验证锚点 ✓

## 本次踩到的坑（均已验证）

1. **重名覆盖**：25秋555 有 陈霞(R103 四 / R172 综合)、邱建花(R61 三 / R193 视导) 各两行。
   用姓名做 dict key → 后写覆盖先写 → 总额 1272990；按行累加 = 1289380，差 16390。
   **教训：姓名匹配前先 Counter 查重；重名按行处理或问用户。**
2. **多列求和公式**：S 列是 `=E186+G186+...` 8 列相加，只写 `=X*N` 单列解析会返回 0。
   需 split('+') 逐项递归（见 SKILL.md「多列求和公式解析」节）。
3. **硬编码 S 行**：25秋555 有 11 行 S 是直接填数字非公式：
   - 马娜/房敏/李欣/田佩琦/王钰/徐倩倩/圣秋梅 = 10800，黄小钰 = 11000（8 人，硬编码 86600）
   - 王晨蕊 780、李海燕 720、邱建花(视导) 150、顾晓俊 4800、卞一凡 4500（特殊行）
   硬编码合计 96050。核对时硬编码与公式行分开统计。
4. **疑似同一人跨表写法不同**（不自动合并，标注让用户确认）：
   徐慧婷↔徐惠婷、李嘉慧↔李佳慧、蒋加杰↔蒋佳杰、陈芳（音乐）↔陈芳（音）、
   京剧辅助（刘晴）↔刘晴。25秋 另有 万金/王梓萌/聂世博/顾晓俊/黄梅戏辅助（冯绒）无 26春 对应；
   26春 另有 20 人无 25秋 对应（何剑云/刘晴/卫海燕/吴凤晔/周明明/曹雅/朱亚丹/汤羽彤/浩志刚/
   王小军/纪慧敏/肖月/陆校/陈霞（美术）/骆美琦 等）。
5. **总额一致 ≠ 口径一致**：26春333（3稿）与上轮 2稿 相比：
   弹性 297730→288873（-8857，单价 三28四28五34六34 → 三27四27五33六33）、
   优学学生 0→6540（19 名学生又算上，与「优学不计算」规则冲突）、
   普调 1733→4050（+2317，几乎全员 26/27）。
   三项恰好抵消，总额都是 1120833。**核对金额不能只看总额，要逐项对比分项构成。**
   上轮规则（优学不计/钱忠网忽略/弹性按最新/曹云兰等没问题）与 3稿 口径冲突 → 挂起等用户确认。
