# Excel 费用核算表改价（openpyxl）

用户定期要按"参考学期表"的模式调整费用表单价（课后服务费、绩效单价等）。**次数一律不动，只改单价/补漏算项**。与 chinese-enterprise-excel-editing 伞技能互补：伞技能管人员合并/去重，本技能管**公式级改价 + 约束枚举 + 模拟验证**。

## 触发条件

- 用户说"按 X 学期的模式改单价"、"确保不超额"、"不要普调"、"某某项费用补算"
- 修改对象是**公式列**（`=L40*30` 这类）而非值，改后要控制总额 ≤ 目标

## 工作流

1. **读表头定列号**：先打印 R1 表头 1:21 逐列映射列名（`headers2.py` 式），**别凭记忆写列号**（本会话凭记忆用错列号直接崩：弹性=col12 不是 14、优学=col16 不是 18、普调=col20、合计=col21）。
2. **备份双轨**：`_备份.xlsx`（改前，保留全部缓存值，是模拟验证的唯一基准）+ 带标签备份（如 `_备份2_改价前.xlsx`）。
3. **公式结构抽查（data_only=False）**：同一列公式可能不统一——U 列部分行含普调 `+T###`、部分行不含。打印 8-10 个代表行公式。用户"不要普调" = `re.sub(r'\+T\d+','',u)` 删引用，T 数据列保留。
4. **底部合计区解码（读全行所有列）**：标签（"行政"/"目前"/"剩余"）混排在无关列；值硬编码（目前=1120712）与公式（合计=`=SUM(...)`、剩余=`=D210-H210-J210`）并存。**汇总公式行（`S=SUM(S2:S201)`、`R203=SUM(U2:U202)`）列加总会重复计算 → 核对用逐行枚举（R2-R200）而非整列 sum**。硬编码"目前"改后手动更新；公式型"剩余"自动算。
5. **约束枚举**：整数单价组合（各年级逐层上升、总额 ≤ 目标、只涨不降）用 itertools 暴力枚举；枚举前用备份缓存算准**真实次数分解**（含特殊行/混合年级老师归属——别凭记忆的 L 值，本会话枚举脚本 L 值错导致差 22）。给用户 2-3 个候选（差额、单价变化、年级总额是否上升）用 clarify 拍板，铁律不猜数据。
6. **改公式**：只改乘数（`=L40*30` → `=L40*27`）；硬编码行（混合年级老师如钱忠网 M=840）直接写值；特殊行（离职/产假补充行）保持参考单价不动。
7. **模拟验证（改后 data_only 读不到公式结果=None 是正常现象）**：
   - ① `data_only=False` 查公式结构（M 乘数分布 / U 无 T / 补算行数）
   - ② 基于备份缓存模拟：新总额 = 旧列加总 − 旧弹性 + 新弹性 + 补算项
   - ③ 告知用户 WPS/Excel 打开自动重算（别依赖 headless：本机无 LibreOffice，WPS headless 超时）
8. **补算漏项**：有次数无金额的行（如优学 P 有值 Q 空白）→ 金额列填 `=P{r}*单价`；已算行若是公式别重复补。

## 关键坑

- **混合年级老师**（B列="二、三"）：K/M 常硬编码非公式；拆年级算（33×20+6×30=840）；拆分次数和 = 表内总数 = 用户口径可信；不吻合 → clarify 问用户。
- **用户口头总额 vs 表内硬编码**（如口头 1109833 vs 表内 1120712）：差异要显式演算（= 合计 − 行政 − 陆校 − 卞一凡），不能默默二选一。
- **"差 N 元"的方案**：无精确解时给最接近且不超额的组合，差额标清楚让用户拍板（用户可能接受差 99 元换取"只涨不降+严格逐层上升"）。
- **openpyxl 保存公式后无缓存值**：data_only=True 读改后文件得 None 是正常现象，不是文件坏了；WPS/Excel 打开即自动重算。
