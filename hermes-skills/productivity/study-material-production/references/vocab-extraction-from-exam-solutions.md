# 从英语二真题解析里抽生词（生词汇总类产物）

用户口径（逐字）：「帮我把知识库中的英语二真题解析中的生词挑出来单独形成一个文档」。

产物：`JesseYoung/MBA/真题素材/英语二_生词汇总_<起>-<止>_v1.0.md`（命名沿用同目录惯例 `科目_板块_年份范围_v1.0.md`，同目录样本：`英语二_阅读_2010-2021_v1.0.md`、`英语二_完形填空_2010-2021_v1.0.md`、`管综_数学_2009-2021_v1.0.md`）。

**口径例外要主动声明**：素材库其他文件按「剔除近五年」处理，生词表是词条工具（不含题目与答案、不影响刷题），**保留到最新年份**，并在 `真题素材索引_v1.0.md` 里写清这条例外，否则与库内既有口径冲突。

## 数据源

`真题库/英语二/2. 2010-2026年考研英语二真题及解析/02、解析部分/`。解析 PDF 有**两种体例**，解析器必须都吃：

- 常规年：生词按 `① ② ③` 编号成块（「词汇注释」「经典搭配」板块）。
- 2024 年：**逐题细解**体例，无编号，生词散在题解里 → 用 `label_mode` 回退解析。判据 = 「短行 + 音标方括号 + 词性缩写」。

## 流水线（四步，脚本已归档在 `98 hermes/英语二生词/`）

1. `ocr_conf.py <年份...>`：断点续跑 OCR，逐页写 `vocab_conf_by_year/<年>.json`，走 `-u` 无缓冲；一次跑一年全部 401/501 页并打印 `ALL DONE`。
   **不要用后台并行多实例**：三个后台任务都拿到 `EXIT=143`（被 SIGTERM），但外层 shell 仍回 `exit 0` —— 只看 exit code 会误判成功。判成功的唯一证据 = 日志尾部有 `ALL DONE` 且内部 `EXIT=0`、且每年 json 页数齐全。
2. `run_vparse.py` → `vocab_entries.json`：两级解析，先 `iter_entries`，空则回退 `label_mode`；收尾清洗统一走 `finalize()`。
3. `build_doc.py`：渲染成文。释义合并统一走 `merge_mean()`。
4. 落库：产物 cp 进 `真题素材/` + 修 `真题素材索引_v1.0.md` + 追加 `wiki/log.md` + 更新 `wiki/index.md` + commit/push。

计数（2010—2024）：抽取 2186 条 → 去重 2149 条（生词 1308 / 短语 610 / 跨年高频 167）。

## 产物结构（用户认这个骨架）

一、跨年高频生词（出现 ≥2 年，按出现年数降序）→ 二、分年份生词表 15 年（生词＋短语搭配，按解析顺序）→ 三、去重字母序总表（3.1 生词带音标＋出现年份 / 3.2 短语搭配）。

## 解析器硬规则（踩过的坑）

- **音标方括号被 OCR 成 `L…` 并粘进词头**（`apparentlyL parantl`）：`^([A-Za-z][A-Za-z'\-]{2,})\s*L[A-Za-z\s]*$` 截断还原。
- **OCR 错字**走 `FIXMAP`：能映射到正确词的还原（`decp-scated→deep-seated`、`eiminate→eliminate`、`overwheimed→overwhelmed`、`plav→play`），还原不了的置 `None` 丢弃（`Dhit`、`gluefglu`、`dimate`）。
- **两层噪声**分开：`JUNK` = 广告/公众号/包邮/打印/QQ音乐/淘宝/网课/真题网/长数字；`JUNK2` = 真题解析噪声（`［A-G］`、干扰项、参考译文、定位、点睛）→ `split(...)[0]` 截断。
- **多字英文散文行不是词条**：英文词数 ≥2 → `prose=True; continue`。
- **释义跨年堆叠**（`assume`）：`merge_mean()` 按 `；` 切段去重、丢残段、去被包含的短段、**同词头只留最长** → `假定，臆断，想当然地认为；承担`。
- **释义夹带解析正文**：单段汉字 >28 字截为前 10 字 + `…`；分年表 cap=4 段、高频表 cap=6 段（改完复查「全表超 60 字释义 = 0 条」）。
- **音标一律重标**：原 PDF 音标字体编码损坏，统一用 CMU 词典 `eng_to_ipa`（缺则留空），并写进文档头说明。
- **文档头必须写**：来源目录、范围/口径例外、体例提示（2024 逐题细解）、音标来源、「个别释义/词性可能有误」的免责声明。
- 词表类产物**不写进 hub 资料地图逐条列**，只在 `真题素材索引` 里挂一节并指明 `[[文件名]]`。
- 遗留瑕疵如实写进回执不粉饰（例：`note` 的释义含源解析并入的「气氛，特征」条；`acre` 的「0.405 公项」是源 PDF「公顷」错字）。
