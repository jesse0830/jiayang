# 真题原文获取与抽取（考研英语二 / 管理类联考语料）

触发：日更练习卷要用真题原文、手头没有真题册；或既有抓取快照需要重新抽成题面/选项/答案。目标 = 拿到**可逐字引用**的正文与**可信的答案**，而不是「看起来像真题」的仿写。

## 1. 来源与 URL 模式

- 全文主源：中国教育在线 `kaoyan.eol.cn/shiti/yingyu/<yyyymm>/t<yyyymmdd>_<docid><page>.shtml`，正文按页切开，`page` 从 0 或 1 起逐页 +1 直到失效。检索拿到某年的 `docid` 后就固定不变（已确认可用：英语二 2016 = docid 1397152，页码 1—8；2015 = docid 1397233，页码 0—8）。
- 抓取方式：`browser_exec` 逐页 `goto_url` → `wait_for_load` → 取 `document.body.innerText` → 一页写一个文件（`<year>_p<page>.txt`）。**不要一次抓 8 页再一起打印**（见第 5 节）。
- 答案/解析辅助源：第三方答案解析页（海文、闽南网、51test 等）。检索多引擎并行，360（`so.com`）用 `h3 a`、DuckDuckGo HTML 版用 `a.result__a`、Bing 用 `#b_results h2 a` 最稳。
- **至少两源交叉**；某源的关键词校验命中全为 0（`-1`/0）即判无效页，直接弃用，不要用它填选项。

## 2. 分页快照的结构（eol 版式）

| 元素 | 判据 / 正则 |
|---|---|
| 正文段落 | 非空行且不以题号、选项标记开头；**一行一段**（续行行首非大写、上一行未收句号 → 拼回上一段） |
| 题干 | `^(\d{2})\.\s+` |
| 选项 | `^\[([A-D])\]\s*(.+)$`，与题干行交替出现（中间常夹空行） |
| 答案行 | `^(\d{2})\s*答案\s*([A-D])\s*(.+)$`，括号内是答案**词** |
| 解析 | 紧跟答案行，页面上常只留约 60 字即被截断 → 只作辅助证据，不算独立来源 |

段落正文一律在题号之前；先定位篇目标题（`Text 3`、`Section I` 等），再按行号把该篇的段落切出来。

## 3. 抽取规程（唯一可靠路径）

1. 脚本从分页快照抽目标段落/题目/答案，**写成独立小文件**（如 `~/.hermes/cache/scratch/t3_passage.txt`），脚本本身只打印一行摘要（段落数 + 字符数）。
2. `read_file` 全量直读该小文件；单文件、≤约 2500 字符才不会被上下文压缩。
3. 正文与答案**分开抽成两个文件**，避免一次读太多被裁。
4. 抽之前先 `ls -l` 看快照大小，确认这份快照里确实含目标篇目（抓取页可能是目录页或含多余篇目）。

## 4. 源页错字 / 脱字的固定处理

- OCR 损伤的常见形态，逐词过一遍：尾字母多打（`signall`→`signal`）、首字母错（`cede`→`code`）、缺字母（`resis`→`resist`、`predictl`→`predict`）、`I`/`l` 与 `i`/`1` 混淆（`Iogical`→`logical`）、词形未还原（`ungreatful`→`ungrateful`、`misinterprete`→`misinterpreted`）、连字符数字（`27-yaear-old`→`27-year-old`）、短语被拆（`pay ma`→`pay my`、`to mark that happen`→`to make that happen`）。
- 题干尾部的 `?????` 之类抓取垃圾直接剥掉；中文标点统一（`，。：`→ `, . :`）。
- 源页**真的缺词**时用 `[ ]` 标出，并在卷头声明里写明「第 X 段源页缺词，以 `[ ]` 标注」；**绝不悄悄补齐** —— 原文完整性是这份卷子可信度的基础。

## 5. 答案归位：词是权威，字母只作定位

源页有两类损伤会让「字母 ↔ 选项文本」对不上：选项词被吞进正文行或某选项缺失；答案块字母与紧随其后的解析文字点名的字母不一致。

1. 取答案**词**（官方答案块内的词）为唯一权威。
2. 把该词放到官方键定的字母位置，其余三项按源页相对顺序补齐。
3. 断言 `opts[letter] == answer_word`（逐个空位过一遍），再断言每空恰 4 个选项、组内不重复。
4. 选项次序与官方册不同属正常，但**必须在速查表下声明真实字母分布**。

## 6. 素材缓存与选材去重

- 抓下的分页快照与抽好的段落文件留在浏览器工作区 / scratch，**下一套卷子先找现成快照**，不要重复抓同一年份。
- 选材前先查前几天的卷子用了哪几篇（`grep -n "^## \|Passage\|完形\|^# 第 3 部分" <上一份英语卷>`）：同一篇正文只用一次；完形与阅读可以跨年份混搭，但不要与上一套撞篇。
- 同一年原卷 Part A 有 4 篇，一次取 2 篇（第 21—30 题），另 2 篇留作下一套，卷头写明还剩哪几篇。

## 7. 卷头声明的必写项

来源（站点 + 具体分页 URL）、年份与选年口径（避开近五年）、本卷取原卷哪几篇 / 还剩哪几篇、脱字与改字处理、**各版本真题册选项次序可能不同 → 答案字母以本文件选项顺序为准**。

## 8. 交付前复核（与 SKILL.md 英语日更第 7 条配套）

复核脚本独立重算、不复用数据模块答案；断言项固定：答案 1—30 齐全、速查表「正确词」== 选项表中该字母指向的词、阅读速查表字母 == 解析标题字母、实际分布 == 声明分布、题干全在 `# 第 4 部分` 之前、21—30 每题恰四个选项、完形正文里 `[1]…[20]` 20 个空位。**FAIL 数与明细写进文件再读**，不要只看终端回执。
