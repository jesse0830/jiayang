# 从题图解题：读图 → 量图 → 容斥 → 反查选项

适用：用户发来数学题截图（多为管综几何/面积/阴影），要求「解法」。目标是给出可复核的分步过程，而不是猜一个字母。

## 1. 先取题源（拿到完整题干与选项）

```bash
# 在 vault 的真题素材里按题干特征词找
rg -n "正方形重叠|三个边长为1|边长均为1的正方形" \
  ~/Documents/work/jiayang/obsidian-vault/JesseYoung/MBA/真题素材/
```

命中后 `read_file` 取题干 + 五个选项（管综是 A–E 五选一）。定位到年份题号写进答复，用户可自行回查。

**为什么要先做这步**：截图常常只截了图形与题干一两行，选项被裁掉；而自算得到的是一个数值，没有选项就无法确认落点，也无法拿错项讲陷阱。

## 2. 量图（像素 → 顶点）

```python
from PIL import Image
im = Image.open(src); print(im.size, im.mode)   # 先看尺寸，别凭想象裁
```

递归二分定位图形区最省事：按列切一半，比较左右半边的「非白像素数」，哪边多往哪边走，直到找到图形所在列区间；也可先灰度 → 4px/字符打 ASCII 缩略图目测列范围（阈值三档：`<110` = `#`、`<190` = `+`、`>235` = 空格）。

裁剪 + 放大后再提线：

```python
crop = im.crop((x0, y0, x1, y1)).convert('L').resize(((x1-x0)*2, (y1-y0)*2), Image.LANCZOS)
import cv2, numpy as np
edges = cv2.Canny(np.array(crop), 50, 150)
lines = cv2.HoughLinesP(edges, 1, np.pi/180, threshold=25, minLineLength=18, maxLineGap=4)
```

`threshold=25 / minLineLength=18 / maxLineGap=4` 在 2× 放大的题图上足够稳；虚线会被切成多段，`minLineLength` 太小会把文字笔画也当线，太大则虚线全丢 —— 两难时先只取实线，虚线靠几何约束补齐。

把线段按角度聚类（水平/垂直/±30°/±60°），同类直线联立求交点得顶点坐标。

## 3. 像素 → 精确模型（关键一步）

**不要把像素角度当答案。** 做法是：

1. 用一个已知量归一化（如题给边长 1 ⟹ 像素长度 / 边长像素数）。
2. 从图上读出**拓扑关系**（哪个顶点落在哪个顶点/边上、谁与谁共点），用几何约束反推角度：例如若两斜正方形的相邻顶点落在上正方形底边两端且共顶点，则连线长度 = 1 = 底边 ⟹ 正三角形 ⟹ 角度锁死为 60°/30°。
3. 用锁定的角度重算所有顶点，得到精确坐标（含根号），像素只用于验证拓扑，不用于定值。

这样最后的答案才可能是 `3 - 3√3/4` 这种精确式，能与选项对上。

## 4. 求交与容斥

```python
import cv2, numpy as np
def poly(pts):  # 必须是 float32 的 Nx2，且顶点按同一方向排列、凸
    return np.array(pts, dtype=np.float32).reshape(-1, 1, 2)

area, _ = cv2.intersectConvexConvex(poly(A), poly(B))   # 返回 (面积, 交集多边形)
```

- `intersectConvexConvex` **只吃凸多边形**，顶点顺序混了会算出 0 或崩，先 `cv2.contourArea` 自查方向与面积是否为正。
- 三重交集不要靠连续求交再猜：显式构造（三块公共区通常是三角形/四边形），用 shoelace 单独算，再和「两两交 ⊇ 三重交」做包含关系检查。
- 容斥：`S = ΣSi − ΣSi∩j + ΣSi∩j∩k`（三块到一个加回项）。两两交若三块相同值，直接用 `3 − 3x + y`。

## 5. 反查选项（必须做）

把五个选项的表达式逐个求值（`math.sqrt` 直接写，或 `sympy.simplify` 确认精确式相等），与算得值比到 `1e-6`，确认**唯一命中**。然后：

- 若算得值恰好等于「漏加回公共部分」的那个错项（如 `3 − √3`），说明该错项就是本题设计的陷阱 → 写进答复的易错点，用户下次会自己避开。
- 若没有任何选项匹配，回第 2、3 步：多半是拓扑读错（虚线当实线、斜正方形顶点落错边），不要硬凑选项。

## 6. 答复骨架

```
答案：<字母> <精确式>（≈ 数值）
一、读图（虚线含义 + 关键推论，一两句）
二、分步计算（每块交集一个式子，给数值）
三、容斥收尾（式子 → 数值 → 合理性检查，如「比两块小、比一块大」）
四、易错点（每条对应一个具体错项）
五、可迁移结论（万能容斥式；1:√3:2 直角三角形里 √3/3、2√3/3、√3/4 常出现）
```

配图用 SVG/HTML 落 scratch（标出公共区、标顶点字母），`::preview{file="<绝对路径>.html"}` 单独一行内嵌。

## 7. 执行坑

- 脚本含绝对路径时终端守卫偶发崩（null byte）：把脚本写进 scratch/`/tmp` 再用 `PYTHONPATH= python3 <脚本>` 跑。
- `skimage` 可能未装；`cv2` + `numpy` 已够用，别在依赖上折腾。
- 视觉模型对细线条几何图的描述往往只有一句概括，用来初判可以，**解题结论必须来自像素测量或几何推理**。
- 输出被压缩器截断时（常见于大段坐标打印），把关键量（面积、顶点、候选式比对结果）压成一两行 `print`，别一次打印全部中间数据。
