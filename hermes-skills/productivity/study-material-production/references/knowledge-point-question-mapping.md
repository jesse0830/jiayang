# 知识点 ↔ 真题对应表

把「考点归纳文档」和「历年真题语料」缝成一张可查表。用户拿它做题、做题后回查，所以**正确性优先于覆盖面**：宁可标注「真题未覆盖，用改编案例」，也不要放一条错答案。

## 交付物骨架

```markdown
# MBA ... 知识点 ↔ 真题对应表 v1.0

> 用法：先看考点，再看下面 1–2 道真题 —— 这个考点在卷子上长什么样。
> 答案说明：题干来自 ... 年真题页原文；部分年份选项文本抓取不完整，故以「题干 + 考点 + 解法」为主，答案字母仅作定位，个别题给自算结果。
> 阅读提示：网页原文上标丢失 —— 题干里的 a3、x2 表示 a³、x²，「丨a丨」表示 |a|。

## 第 N 章 <章名>
### 1.1 <考点名>
- 提示：<一句话手筋>
- **<年份>-<题号>**（<题型/来源>）
  - 题干：…
  - 为什么是这个考点：…
  - 解法要点：
    - …（2–4 条，最后一条常是「手筋：…」）
  - 参考答案：…

## 附0 · 结构/清单/计划类条目（不挂真题，说明它的用法）
## 附1 · 反向索引（按年份查：这道题考的是哪个点）
## 附2 · 真题未覆盖考点（改编案例补位）
```

## 数据/渲染分层

- `*_cases.py`：主数据，`CH = [ {t: 章名, secs: [ {kp: 考点名, tip: 手筋, cases: [ {y, n, why, pts, res} ]} ]} ]`，另加 `GAPS = [ {kp, note, q, a, pts} ]`（无真题覆盖的改编案例）。
- `*_extra.py`：补充考点（同上结构 + `EXTRA_GAPS` + `STRUCT` 纯结构条目清单）。**永远新增在 extra，不改主数据文件**。
- `build_*.py`：只读数据渲染，开头 `CH_ALL = list(CH) + EXTRA_CH`，正文循环与反向索引循环**都**要用 `CH_ALL` / `list(GAPS) + EXTRA_GAPS`。
- 案例渲染逐条自检：年份、题号、题干是否为空、`res` 缺失时是否回落源页答案字母。

## 覆盖率自检（每次补完必跑）

```python
# 1) 归纳文档的标题清单（read_file 会带 "N:" 行号前缀，先剥掉）
import re
heads = [re.sub(r"^\d+:", "", l).strip() for l in open("_headings.txt")]
heads = [h for h in heads if re.match(r"^#{2,4} ", h)]
# 2) 数据里的考点名，正则对齐两侧的编号（如 "3.4.1"）后求差集
# 3) 差集里逐条判断：是真空缺 → 补进 extra；还是结构/清单/计划类 → 进 STRUCT 清单
```

- 抓取到的标题文件常带行号前缀，不剥掉会「全部不匹配」，白白以为缺了一百条。
- 章节级条目（如「4.5 不等式」）不算缺考点：它的小节已挂题时，把它列入 STRUCT 清单即可。

## 真题语料的三类残缺与处理

| 表现 | 处理 |
|---|---|
| 选项只剩字母（`A ｜ B ｜ C ｜ D ｜ E`） | 渲染器判定「任一选项去掉字母/分隔符后长度 ≤3」时整行不输出 |
| 上标丢失（`a3`、`x2`、`丨a丨`） | 文档头加阅读提示，不改写题干（改写会误伤年份数字） |
| 条件/题干被截断 | 不引用条件原文，不写「(1)/(2) 分别充分」的结论；必要时换一道完整题 |

## 答案处理（最重要）

1. 每道题的答案**自己算一遍**，写进解法要点。
2. 源页答案字母与自算冲突 → 不要照抄，也不要用它当「题型示例」；换一道已验算的题顶上。
3. 年份久、选项抓取不全的题（例：某年源页选项为图片）→ 保留题干与解法，答案行注明「源页答案位 X，选项文本未完整抓取，以计算结果为准」。
4. 条件充分性判断题至少要能说清「单条件充分 / 联合充分 / 均不充分」，不确定就明写「以官方解析为准」，不要猜字母。
