# 劳动合同续签 / 试用期转正审视理由撰写

同一份绩效库除了排名和调薪测算，还要支撑人事结论：主管要按公司给的四条维度（能力 /
意愿价值观 / 相对位置 / 经营）写"续签或不续签的理由"。产物是**一份 md**，不回写 HR 的
xlsx——用户会明确说"不用写到 excel 里"。

## 1. 先读输入表，再取数

输入 xlsx 前几行是标题/说明区，人员行按**姓名匹配**定位，不要硬编码行号：

```python
import openpyxl
ws = openpyxl.load_workbook(path, data_only=True).worksheets[0]
for row in ws.iter_rows():
    for c in row:
        if c.value and "姓名关键词" in str(c.value):
            ...
```

长输出同样会被压成 "1 lines output"：脚本写 `/tmp/rd.py` 再用 `terminal` 跑、`head` 截取。

绩效取数走 `_perf48_raw.json`（`rows` 里每人 `name/dept/M/A/B/C/n`）+ 窗口报告 md，
不要凭印象写"近几个月表现"。

**部门口径可以不一致，但要说清楚**：输入表写"客户成功部-软件工厂"，绩效库三级部门写
"配置开发部"。文中结论与结论表用输入表口径，统计用绩效库分组，一句话说明归属差异即可，
不要为了统一而改数。

## 2. 相对维度靠分组分布，不靠感觉

这是唯一能支撑"中等偏上还是下游"的硬证据，必须现算：

```python
cfg = [r for r in rows if r["dept"] == dept]
n = len(cfg)                      # 分母
A档  = sum(1 for r in cfg if r["A"] >= 1)
全B档 = sum(1 for r in cfg if r["A"] == 0 and r["C"] == 0 and r["n"] >= 4)
C档  = sum(1 for r in cfg if r["C"] >= 1)
人均A = round(sum(r["A"] for r in rows) / len(rows), 2)
```

**关键修正：0 个 A 不等于下游。** 在软件工厂 0A 是多数派（配置开发部 54/73，全厂 82/110，
人均 A 0.43），所以单个 0A 不能当作"不称职"证据。三档判定：

| 画像 | 含义 | 结论措辞 |
|---|---|---|
| 有 A（部门内约 1/4 的人） | 中上 | 有被记录的超额贡献 |
| 0A 0C | 中游、无区分度 | "稳定达标，但没有一次被认定超额" |
| 有 C | 下游 | 唯一能写"属于尾部"的情形 |

必须把三档的**人数与占比**写进文档，否则理由读起来像主观评价。

## 3. 四维度的写法

**① 能力（长期绩效与潜力）**：A/B/C 序列 + 专业对口度（本科专业、第一学历、是否转岗适配）。
0A 的准确表述是"没有被记录的超额产出"，不是"表现差"；结论落到"满足现岗基线 /
不具备晋级证据 / 潜力和通道已有但未验证"。

**② 意愿与价值观**：**只能写可核查记录**——无违纪、无客户投诉、无协作冲突上报。
不得编造"发牢骚、搞内耗"这类事实，那是人事结论里最容易被反问的一句。没有观察时的诚实写法：
"无负向行为记录，属被动执行型，管理成本低但不产生额外正贡献"（0 个 A 本身就是主动性未被
认可的客观痕迹）。同时在给用户的回复里点明：这一维度需要他补 1-2 个具体事例。

**③ 相对（团队位置）**：用第 2 节的三档 + 人数占比，结论只落在"下游 / 中游 / 中等偏上"之一。

**④ 经营（贡献 vs 成本）**：**不要编薪酬数字**。用职级 + 司龄 + 绩效档位推：B 档 = 贡献≈成本；
职级高一级而同绩效 = 单位产出成本更高。把"薪酬在带宽中的分位"作为 HR 待办（写清接口人），
并给出判定规则：分位在带宽上沿（≥75%）而绩效仍是 B，即为 overpay，续签时应转为绩效浮动。

## 4. 结论口径："从严"落在条件，不落在清退

用户要的导向是"实事求是、理性＞感性、从严"。达标员工（B、无 C、无违纪）的默认结论是：

**续签 + 书面条件 + 不调薪不晋级**，条件形如"续签后 12 个月内至少取得 1 个 A 或完成 1 项
量化目标，未达成不再续签"。

必须把不续签的成本算出来，这才是"理性"：经济补偿（司龄约 3 年 ≈ 3 个月工资）+ 招聘重置
（1.5-2 个月薪酬）+ 产能空窗，通常高于"留一年并施加条件"。原话可写："从严应该严在条件和
结果上，而不是严在情绪化的清退上。"

**若公司名额上必须压降 1 人**，单独一节给保留顺位，依据只用可核查差异：专业对口度（科班
vs 转岗）、职级与成本、可替代性（同档人数与市场稀缺度）。不要用"态度"这类不可证的说法。

## 5. 合同节点与交付

- 到期日与今天相差 ≤15 天，单列待办：不启动续签手续会形成事实劳动关系风险。
- 签约主体若是第三方公司（如麟软），说明续签文本由该主体出具，软件工厂只出审视意见。
- 第一次固定期限到期 = 第二次签约，仍为固定期限；第三次才进入无固定期限，写清这个层级。
- 文件名：`劳动合同续签审视_<部门>_<N>人_<日期>_v<版本>.md`，落 `98 hermes/`，版本号从 v1.0 起。
- 结构：结论速览表（工号/姓名/职级/到期日/是否续签/一句话理由）→ 绩效底稿与部门分布 →
  逐人四维度 + 结论条件 → 从严预案（压降顺位）→ 待办。
