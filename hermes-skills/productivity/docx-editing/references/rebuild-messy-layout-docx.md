## 3. 1×1 框的四种还原规则

| 判定条件 | 还原为 | 实测数量 |

| 上一段以 `：` 结尾，框内 ≤40 字 | 合并成一句完整的话，框内文字加粗（`p2`） | 140 |

## 4. 三个坑（都会静默毁内容）

1. **单元格文本里的换行不能替换成空格。**
   `cell.text.replace('\n', ' ')` 会把 ASCII 图形（`│  ├─`）抹平成一行乱码。
   正确：`raw.append(('t1', tb.rows[0].cells[0].text.strip(), None))` 保留原始 `\n`。
   （定位过程：流程图"没被识别" —— 加诊断打印发现框内容变成一长串、`FORK` 正则永不命中。）
2. **`run._element.rPr.rFonts` 可能是 None。**
   `r._element.rPr.rFonts` 直接访问 → AttributeError；改用
   `rf = r._element.get_or_add_rPr().get_or_add_rFonts()` 再 `rf.set(qn('w:ascii'), 'Consolas')`，中文等宽另设 `w:eastAsia`。
3. **不要拿 dump 出来的文本判断"原文句子被截断"。**
   dump 脚本常按行截断，会看到"前者决""业务流能力…基线能力需"这类假截断。
   这次我据此列了 3 条"原文残缺"，回真实文档一搜全是完整的（`前者决定 AE 的产出能不能被评价和复用`）→ **报告前必须在真实 docx 文本里 grep 复核**。
