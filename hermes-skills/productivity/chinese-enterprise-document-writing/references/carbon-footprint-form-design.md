# 碳迹记录表单设计参考（适用于零代码平台）

## 适用场景

学术调研报告（课题报告）中"系统/工具设计"章节的延伸——当子课题核心是"用零代码工具设计碳迹记录表单"时，需要提供一份平台无关的字段配置清单 + 计算逻辑，让用户自行到简道云/表单大师/腾讯问卷等平台配置。

## 关键原则

- **平台无关**：不依赖特定零代码平台的截图/API，只提供字段类型、选项、计算逻辑
- **即配即用**：用户拿到后可以直接照着配置，不需要二次设计
- **自动计算**：设计自动计算字段，让游客填写完选项后自动得到碳足迹数值

## 表单结构（6步）

| 步骤 | 内容 | 字段数 |
|:----|:-----|:------:|
| 第1步：基本信息 | 昵称、同行人数、游玩日期、游玩时长 | 4 |
| 第2步：交通碳迹 | 到达方式、距离、景区代步方式、代步距离 | 4 |
| 第3步：住宿碳迹 | 是否住宿、住宿类型、住宿天数（仅住宿者填） | 3 |
| 第4步：餐饮碳迹 | 用餐顿数、餐饮类型、光盘行为 | 3 |
| 第5步：游览活动碳迹 | 活动多选、购物消费、垃圾处理 | 3 |
| 第6步：低碳行为加分 | 低碳行为多选、额外善举、碳迹报告意愿 | 3 |

## 碳排放因子参考表

### 交通因子（kgCO₂/km）

| 交通方式 | 因子值 |
|:---------|:------:|
| 新能源自驾 | 0.08 |
| 燃油自驾 | 0.20 |
| 旅游大巴 | 0.035 |
| 公共交通（公交/网约车） | 0.05 |
| 骑行/步行 | 0 |
| 景区新能源接驳车 | 0.03 |
| 租赁自行车/电瓶车 | 0.02 |

### 住宿因子（kgCO₂/间/晚）

| 住宿类型 | 因子值 |
|:---------|:------:|
| 低碳/绿色酒店 | 0.50 |
| 普通酒店/宾馆 | 1.50 |
| 民宿/农家乐 | 0.80 |
| 帐篷露营 | 0.20 |

### 餐饮因子（kgCO₂/顿）

| 餐饮类型 | 因子值 |
|:---------|:------:|
| 荤素搭配 | 1.20 |
| 全素食为主 | 0.60 |
| 快餐/简餐/小吃 | 0.80 |

### 活动与行为

| 项目 | 因子值 |
|:----|:------:|
| 每项游览活动 | 0.20 kgCO₂ |
| 每项低碳行为（抵消） | -0.15 kgCO₂ |

## 自动计算逻辑

```
交通碳迹 = 到达距离 × 到达方式因子 + 代步距离 × 代步方式因子
住宿碳迹 = 住宿天数 × 住宿类型因子  （不住宿则为0）
餐饮碳迹 = 用餐顿数 × 餐饮类型因子
活动碳迹 = 0.20 × 活动选中项数 + 购物因子(0.10) + 垃圾处理因子(0~0.10)
低碳抵消 = 0.15 × 低碳行为选中项数

总碳足迹 = 交通碳迹 + 住宿碳迹 + 餐饮碳迹 + 活动碳迹 - 低碳抵消
```

## 提交后展示（游客端）

碳迹报告应展示：
- 五大维度碳足迹明细
- 低碳行为抵消量
- 总碳足迹（kgCO₂）
- 生态对照："相当于一棵树XX天的碳吸收量"
- 低碳评级（★★★★☆ 绿色游客）
- 个性化建议（如"下次可以尝试公交出行，减少XX kgCO₂"）

## 管理端统计看板

- 当日填写总量（实时）
- 平均碳足迹趋势
- 交通方式分布（饼图）
- 低碳行为践行率排行
- 高碳项目热力图
