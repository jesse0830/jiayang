# 培训感想文档参考模板

## 适用场景

员工参加公司内部培训后撰写的个人感想/心得体会。适用于管理培训、干部赋能、文化宣讲等场景。

## 核心结构

1. **背景铺垫** — 个人的职业经历 + 培训背景（何时、什么培训）
2. **旧认知** — 参加培训前的理解（简短、真实，引用自己的原话）
3. **认知冲击/新认知** — 培训中对自己触动最大的 3-5 个点，逐条展开
   - 每个点包含：培训观点 → 与自己过去的对比 → 行动转变
4. **自我反思** — 结合自己的行为习惯/缺点，对照培训内容
5. **结合当前岗位** — 新认知在自己的具体岗位上如何落地
6. **总结** — 认知升级对比表 + 表态

## 用户风格特征（针对本用户）

- 管理经历：10年，路径为 研发 → 项目经理 → 管项目经理 → 软件工厂负责人
- 当前岗位：二级部门负责人，核心是**抓执行**，在执行中做战术决策
- 核心价值观：明确期望比提升能力更重要、干部是自己成长的第一责任人
- 个人短板：习惯"不行就自己上"，需要从执行者转向指挥官
- 文档偏好：结构层级清晰、不做形式化、要有真实个人痕迹
- **关键认知框架升级**：三要素(目标→执行→结果) → 四个一(理念一致→目标一致→行动一致→标准一致)
- **另一个关键认知**：从"带团队拿结果的人" → "你就是公司，干部是公司经营的核心力量"

## 典型迭代路径

用户的写作偏好是一次给一点信息，逐步补全。典型的迭代序列：

| 轮次 | 用户给出的信息 |
|------|-------------|
| 1 | 培训PPT名称 + 要求写感想 |
| 2 | "原来我是三级部门负责人，现在是二级部门软件工厂负责人" |
| 3 | "我对管理的理解就是把人管好，把结果拿到" |
| 4 | "我做了十年管理，从研发到项目经理到管项目经理到工厂" |
| 5 | "软件工厂是公司的核心基础生产力" |
| 6 | "现在要更多做决策，而不是做执行细节" → **纠正：你是二级部门，抓执行** |
| 7 | "我最大的优点是缺点，不行就自己上" |
| 8 | "原来我理解三要素，现在发现应该是四个一" |
| 9 | "特别是明确期望比能力提升更重要" |
| 10 | "我原来以为干部就是带团队拿结果，现在明白干部代表公司" |

**预期每次迭代都重写整篇，而不是小修补。** 新信息融入后，整个文章的逻辑层次可能要重新调整。

## 文档结构决策树

根据用户有没有提到以下内容，决定是否增加对应段落：

### 必须存在的段落（用户提到了就写）
- 职业背景（研发→项目经理→PM经理→工厂负责人）
- 旧认知（三要素或"把人管好把结果拿到"）
- 新认知（四个一框架）
- 最大的触动（"明确期望比能力提升更重要"）
- 自我反思（"不行就自己上"的毛病）
- 结合当前岗位（软件工厂定位）

### 可选段落（根据用户是否提到决定）
- 对干部身份的重新认知（"你就是公司"）
- 新旧认知对比表（总结部分）

### 段落顺序
背景 → 旧认知 → 四个一展开 → 触动(明确期望) → 自我反思(不行就自己上) → 结合岗位 → 总结对比表

**如果用户说"帮我分个层级"**，优先按这个顺序重新组织，用带编号的h1/h2标题。

## 注意事项

- **角色纠正的处理**：用户可能先说自己"现在要做更多决策"，然后纠正为"我是二级部门抓执行"。发现纠正后必须重写整篇，不能只改一句话。角色定义是整篇感想的主心骨。
- **个人缺点的处理**：用户的自我缺点（"不行就自己上"）是贯穿全文的线索。每个新认知都应该和这个缺点挂钩——告诉用户这个认知如何帮助他解决这个缺点。
- **避免内容重复**：如果两个小节说了相似的内容（比如标准一致在多个地方出现），合并它们。用户会指出来。
- **不要一次写完就完事**，预留 5-10 轮迭代空间
- **用户的自述原话**（如"不行就自己上"）是最宝贵的素材，尽量保留在文中
- **结构乱了用户会主动说"帮我分个层级"**——准备好重新组织，把内容按"背景→旧认知→新认知→反思→岗位→总结"重新排列
- **最终输出 Word 文档(.docx)**，用 python-docx 生成

## 输出文档规范

### Markdown文档
保存到桌面：`/Users/jesseyoung/Desktop/<文件名>.md`

### Word文档 (.docx)
当用户最终确认内容后要求生成Word文档时，用独立Python脚本生成：
1. pip install python-docx（如未安装）
2. 写独立.py脚本，在脚本中直接嵌入文字内容，不要解析markdown
3. 格式要求：
   - 微软雅黑字体
   - 页边距：上下2.54cm，左右3.17cm
   - 标题22pt加粗居中
   - h1 16pt加粗
   - h2 14pt加粗
   - 正文12pt，1.5倍行距，首行缩进0.74cm
   - 表格用Light Grid Accent 1样式，右列加粗
4. 保存到桌面 .docx
