# 面试公司全面分析指南

## 适用场景

用户要去一家公司面试（或已进入终面），要求全面分析这家公司的口碑、实力、风险。特别适用于：
- 小红书/脉脉口碑差但面试感觉还不错的矛盾情况
- 公开信息少的公司（需警惕）
- 进入CEO终面阶段，需要决策是否继续
- **对比现公司和Offer公司，做去留决策（常见：现公司稳定但有问题，新公司有机会但口碑差）**

## 信息收集策略

### 渠道优先级

| 渠道 | 可信度 | 获取方式 |
|------|--------|---------|
| 企业工商信息（天眼查/企查查/爱企查） | ⭐⭐⭐⭐⭐ | 直接搜索（注意反爬限制） |
| 招聘平台评价（看准网/脉脉/Boss直聘） | ⭐⭐⭐⭐ | 搜索公司名+评价 |
| 小红书/知乎员工吐槽 | ⭐⭐⭐ | 搜索公司名+面试/离职/坑 |
| 新闻/财报（如果是上市公司） | ⭐⭐⭐⭐⭐ | 财经网站、东方财富、雪球 |
| 上市公司公告 | ⭐⭐⭐⭐⭐ | 港交所/上交所公告查询 |
| 百度搜索（正常公司会有官网、新闻） | ⭐⭐⭐ | 公开搜索结果 |
| GitHub/技术社区（如果是技术公司） | ⭐⭐⭐ | 搜公司技术栈 |

### 关键信号评估

**危险信号（1-2条即需谨慎）：**
- 公司全称在公开渠道几乎搜不到任何信息（官网、新闻、招聘信息都没有）
- 只有小红书/脉脉的差评，没有正面的公开信息
- 面试流程不正规、说不清楚岗位定位
- 社保公积金缴纳不规范（招聘评价常见槽点）
- **上市公司无此风险**——有财报、有公告、合规要求严格

**中性信号（需要进一步判断）：**
- 小红书差评多但集中在基层岗位（高级岗位体验可能不同）
- 公司规模小、成立时间短（机会和风险并存）
- 融资阶段不明确

**利好信号：**
- 有明确的业务模式和产品
- 面试官对业务有清晰认知
- 岗位定位和权力边界明确
- CEO能说清楚公司阶段和你的角色
- **港股/A股上市公司**——合规性好、公积金社保大概率没问题
- **新建分部/新大楼的早期核心岗位**——上升空间大、搭体系容易出成绩（适合有体系搭建能力的管理者）
- **不是全员配股，核心岗位才配**——说明公司把你当关键人才定位
- **政府项目背景**——业务稳定、客户质量高（尤其TOB交付管理经验匹配）

## 终面（CEO面）问题清单

当用户进入CEO面时，这些问题是关键：

### 业务和生存状况
- "公司目前的融资阶段和现金流状况如何？"
- "过去一年的营收规模和增长情况？"
- "公司目前的盈利模式是可持续的吗？"

### 岗位真实定位
- "这个岗位是新设的还是前任离职？什么原因？"
- "向我汇报的团队规模和组织架构是怎样的？"
- "公司对这个岗位接下来半年的核心考核指标是什么？"

### 公司真实状态
- "公司目前是在扩张期、稳定期还是收缩期？"
- "项目交付/业务流程的管理体系成熟度如何？"
- "我进来以后最大挑战是什么？"

### 判断标准
- **CEO回避具体问题、画大饼** → 风险极高
- **CEO能清晰回答业务逻辑和你定位** → 可考虑
- **CEO说不清楚岗位职责** → 即使进去也会很累

## Offer对比分析（新增场景）

当用户同时面临"现公司"和"新Offer"两边的选择时，分析框架如下：

### 核心问题清单（必须澄清的差异点）

| 问题 | 为什么重要 |
|------|-----------|
| 公积金缴纳基数和比例 | 直接影响现金收入和房贷额度 |
| 报销周期（月/季度/年） | 现金流影响很大，特别是有招待费垫付的管理岗 |
| 年终奖规则（是否有保底、历史发放情况） | 0-3个月 vs 固定发放差异巨大 |
| 是否会拖欠报销/公积金 | 公司财务健康度的直接指标 |
| 股票配发条件（全员还是核心岗、归属周期、离职处理） | 体现公司对你的定位高度 |
| 汇报关系（向谁汇报、团队规模） | 决定你的话语权和执行效率 |
| 是否是新建团队/新建办公点 | 决定你是"早期核心成员"还是"后来补充" |

### 经济账计算

计算2年期的实际收入差异时，应包括：
- 工资（两边一致时关注） → 其实差异在**公积金**、**股票**、**报销资金占用成本**
- 公积金双边差额 × 24个月
- 股票归属金额（按解锁条件）
- 年终奖（取保守值，如0.5-1个月）
- 报销资金占用（如有垫付周期，按占用金额×占用时间估算机会成本）

示例公式（简化）：
2年收益差 = (公积金差额×24) + 股票解锁金额 + (年终奖差额) - 报销资金占用

### 现公司问题诊断

当用户对现公司有明确吐槽时，需要判断：
- **问题是否会改善** → 如果用户自己判断"3年内不会改变"，这就是硬约束
- **问题的严重程度** → 报销一年多才一次 + 公积金拖欠是现金流紧张的双重信号
- **你的忍耐边界** → 这些问题长期下去是否会影响你的职业判断

### 新公司确定性判断

即使公开信息有限，以下信号可辅助判断：
- **上市公司** → 财报可查，合规性有保障
- **新建分部/新大楼** → 说明公司在扩张，不是收缩
- **核心岗位配股** → 公司愿意用股权绑定，说明岗位定位高
- **业务方向匹配度** → 政府AI、TOB交付等与用户经验直接对口的，转型风险低
- **小红书差评的层次** → 集中在基层（加班、管理乱）vs. 集中在高层（战略方向、资金问题）

### 综合分析框架

商业确定性（上市公司 > 民企） × 职业上升空间（新建团队 > 成熟团队） × 个人匹配度（经验直接平移 > 需要转型） × 隐性成本（报销垫付 + 公积金差额 + 股票）

### 关键诊断问题

问用户一个核心问题，答案往往就能决定方向：
"如果2年后现公司还是现在这个状况，你还会留吗？"
→ 如果答案是不会，那越早走越好，沉没成本只会越来越高。

### 输出格式

Offer对比分析的输出应为结构化文档，包含：
1. **基本信息对比表**（岗位、薪资、公积金、股票、报销、汇报关系等）
2. **2年经济账**（算出真实收入差）
3. **现公司优劣势分析**
4. **新公司优劣势分析**
5. **关键信号解读**（如"核心岗位才配股"、"南京新大楼"等）
6. **最终建议**（提供分析框架和判断依据，让用户自己决策）

## 综合分析框架

| 分析维度 | 判断标准 |
|---------|---------|
| 公开信息量 | 正常公司应有官网、新闻、招聘；完全没有是危险信号 |
| 口碑分布 | 基层差评 vs. 高层口碑；普遍性问题 vs. 个别现象 |
| 面试专业度 | 面试官是否说清楚业务、岗位、团队 |
| CEO终面质量 | CEO是否务实、清晰、坦诚 |
| 你对公司业务的认可度 | 你信不信这家公司能做起来？ |
| 风险和收益平衡 | 失败风险 vs 可能的成长空间和薪酬 |
| 上市公司/非上市 | 上市公司合规性好，公积金/报销/社保基本没问题 |
| 新建分部/核心岗位 | 早期成员机会大，但需要自建体系会很累 |
| 岗位定位 | 核心岗位配股 vs 全员配股，含金量完全不同 |

## 输出格式

给用户的输出应为结构化的分析报告，包含：
1. 信息收集结果（实际的公开信息）
2. 小红口碑差的解读（理性分析）
3. CEO面建议问题
4. 综合判断和建议

**避免**：替用户做决定。提供分析框架和判断依据，让用户自己决策。

**保持**：务实、不煽情、不贩卖焦虑。给出真实的风险信号，也给出可能的利好面。
