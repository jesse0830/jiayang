# 🇬🇧 英语学习记录

每天在 B 站学英语后，用模板 `templates/英语学习模板` 新建一篇笔记（文件名用日期，如 `2026-08-24`），放在本文件夹（JesseYoung）。

## 📅 学习记录

```dataview
TABLE 视频 AS "视频"
FROM "JesseYoung"
WHERE file.name != "英语学习记录"
SORT file.name DESC
```

## 📊 统计

- 学习天数：`=length(link(rows.file.link))`
- 累计生词数：`=sum(rows.生词数)`

> 💡 用法：Obsidian 里按 `Ctrl/Cmd + N` 新建笔记 → 输入日期名 → 用「插入模板」按钮选「英语学习模板」。
