解决从oa跳转到我方系统报错问题。

问题背景：

跳转时，url后拼接了loginid，并且loginid为GBK方式编码，url如下：

http://221.226.83.186:2233&ssoType=jjoa&ts=1763364225929&token=E0DB8D804FC664CC95A0113/applicationview/content/view?appid=1946454466554134&type=view&menuId=1599861388359114%C084BAFD5A46D9D3D4EC1543516685E1AF2C3E9A9B123&loginid=%C1%F5%C0%A5

当前因为浏览器自带的decodeURI无法解码GBK编码内容，因此无法跳转，去掉loginid之后即可跳转。

解决方案：

通过配置nginx转发，以下为解决步骤：

（1）在九江开发环境安装nginx，安装教程：[https://smardaten.yuque.com/gt9f9h/install/mms1qo2erolo5dq1](https://smardaten.yuque.com/gt9f9h/install/mms1qo2erolo5dq1)

（2）修改tomcat端口号，改为没有使用的端口，例如17001；

（3）修改nginx代理，端口号指向原始端口，如18085；

（4）修改nginx代理，截取url，删除loginid

nginx配置文件：

upstream sdataGroup{ server 127.0.0.1:17001; } map $args $filtered_args { default $args; "~(.*)(?:^|&)loginid=[^&]*(&?(.*))" $1$3; } server { listen 15058; server_name _; client_max_body_size 1024m; gzip on; gzip_min_length 1k; gzip_buffers 4 16k; gzip_comp_level 5; gzip_types application/javascript text/plain application/x-javascript text/css application/xml text/javascript application/x-httpd-php; location /applicationview/content/view { if ($args != $filtered_args) { # rewrite ^ /applicationview/content/view?$filtered_args? permanent; return 302 http://221.226.83.186:20113/applicationview/content/view?$filtered_args; } proxy_pass http://sdataGroup; } location / { proxy_pass http://sdataGroup/; proxy_redirect off; proxy_set_header Host $host:$server_port; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; proxy_http_version 1.1; add_header X-Frame-Options ALLOWALL; proxy_hide_header Server; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_connect_timeout 600; proxy_send_timeout 300; proxy_read_timeout 3600; proxy_intercept_errors on; index index.html; } }
